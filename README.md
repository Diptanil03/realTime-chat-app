realTime-chat-app

A real-time chat application.


This project is a simple, real-time chat application that allows users to communicate instantly. It's ideal for developers looking to understand or implement basic WebSocket functionality in a web application. The application is built using React,Tailwind CSS for the frontend and Node.js with Socket.IO for the backend.

*   **Real-time Messaging:** Send and receive messages instantly without page reloads.
*   **User Identification:** Each user is identified by a unique username.
*   **Simple Interface:** Clean and intuitive user interface for easy chat.
*   **Node.js Backend:** Powered by Node.js and Socket.IO for efficient real-time communication.

## Installation

To get started, clone the repository and install the dependencies:

```bash
git clone https://github.com/Diptanil03/realTime-chat-app.git
cd realTime-chat-app
npm install
```

## Usage

Start the server and open `index.html` in your browser:

```bash
node server.js
```

Then, open the `index.html` file in your web browser. Enter a username and start chatting.
